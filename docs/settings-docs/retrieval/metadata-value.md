# Value

## Summary
Enter the comparison value the metadata rule should use.

## Details
### Overview

This is the target value the rule compares against.

Examples:

- `en`
- `true`
- `2025-01-01`
- `official`

Most metadata rule mistakes happen here: the operator is fine, but the value does not match the real metadata.
