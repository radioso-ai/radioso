# Use cases

## Customer-facing agent

Use Radioso when you want a customer-facing agent that answers from controlled workspace content instead of improvising from model priors. Anonymous public chat is available as a public surface. The hosted website widget is available in Enterprise Edition.

## Internal team agent

Use workspace-scoped agents, documents, and settings when different teams or customers need isolated behavior and content.

## API-driven agent workflow

Use the API or SDK when you want Radioso to sit behind your own UI, workflow, or automation.

## MCP-grounded knowledge access

Use the MCP server when an external client should search documents, ask grounded questions, or inspect workspace capabilities without owning Radioso assistant history.
