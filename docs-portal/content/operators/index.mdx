# Operators

Use this section when you are responsible for running Radioso, not just integrating with it.

The key point is that operator work usually starts from one of two questions:

- how the system is deployed
- why background document processing is behaving differently than expected

## Start here

### Deployment

Read [Deployment](/operators/deployment) when you need the production service split, environment expectations, and release checks for the docs portal and application services.

### Document processing

Read [Document processing](/operators/document-processing) when uploads are accepted but the content is not yet searchable, cited, or available to grounded answers.

## Practical guidance

In practice, operators often need adjacent sections while they work:

- [Security](/security) for token handling and public embed safety
- [Troubleshooting](/troubleshooting) for startup and document-processing failures
- [API reference](/api-reference) for exact request and response contracts
