# Retrieval tuning

The highest-leverage settings usually control query rewriting, retrieval depth, similarity filtering, reranking, and metadata rules.

## Start with these

- vector top-k
- similarity threshold
- rerank enabled
- rerank top-k
- metadata rules
- custom instruction
