# Radioso for teams that need answers they can defend

Radioso is built for grounded answers, traceable citations, and embedded support experiences. The goal of this site is simple: get you from evaluation to first success quickly, then give you enough reference material to trust what you are deploying.

<Callout type="info" emoji="↗">
  Three paths matter most: run Radioso locally, embed it on a site, or upload docs and ask through the API.
</Callout>

## What success looks like

<Steps>
### Pick one path

Choose the path that matches your intent: local setup, website embed, or API-first evaluation.

### Reach a visible result

Do not stop at setup. Upload one real document, ask one real question, and verify the answer is grounded.

### Understand the system

Use the architecture and operator guides to understand how retrieval, document processing, and deployment fit together.
</Steps>
