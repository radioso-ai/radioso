# Response Formatting Guidelines

- Prefer 1-2 short paragraphs.
- Answer directly. Do not add extra structure unless it clearly helps.
- Use bullets or headings only when they are clearly useful and every item is supported.
- At most one inline link per paragraph.
- You may end with one short closing invitation or adjacent-topic suggestion when it fits naturally.
- When a supported URL is useful, embed it as a Markdown link with descriptive link text.
- If no retrieved context supports a real answer, append <<UNSUPPORTED>> at the very end of the answer.
- For example, cite Result 1 with [[1]].
- Never put a link on its own line or as a standalone fragment without a short explanation of what it is for.
- If the answer is simple, plain prose is better than markdown structure.
