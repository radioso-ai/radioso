# Rule Enabled

## Summary
Turn this metadata rule on or off without deleting it.

## Details
Turn the rule off to take it out of play without losing its configuration. The key, operator, value, and effect all stay saved; the rule stops shaping this agent's retrieval until you switch it back on.

That makes the toggle the natural tool for comparison and debugging — answer a question with the rule on, then off, to see how much it is really moving results, or park a suspect rule while you chase down a retrieval problem elsewhere. A rule that is off has no effect on any turn.
