# Show Citations

## Summary
Display inline source markers when supporting evidence is available.

## Details
### Overview

This setting controls whether the final answer visibly shows source markers when supporting evidence is available.

### What Changes

- **On:** users see inline source markers
- **Off:** answers look cleaner, but grounding is less visible

### What Does Not Change

- retrieval
- ranking
- evidence selection

This is a presentation and trust setting, not a search-quality setting.
