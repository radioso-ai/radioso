# Data Model: MCP Agent Converse

## Converse Grant

**Storage**: Existing `agent_access_grants` row.

**Fields**:
- `id`: grant id.
- `workspaceId`: owning workspace.
- `agentId`: exactly one bound agent.
- `principalKind`: `public-launch` for converse credentials.
- `channel`: new enum-like value `embed | public-link | mcp-converse`; converse accepts only `mcp-converse`.
- `role`: `agent` for converse; `public` remains for website/public chat.
- `label`: operator-facing label.
- `tokenHash` / encrypted token material: existing hashed + encrypted credential handling.
- `enabled` / revoked state / expiry fields: existing validity controls.
- `updatedAt` or rotation counter: used as the grant version embedded in sessions.

**Validation rules**:
- Converse exchange must resolve by token with `channel = mcp-converse`.
- `public-launch + mcp-converse` defaults to role `agent`.
- Embed/public-link grants fail on converse exchange even when Origin is absent.
- Workspace API tokens are never valid grant tokens or bearer credentials on the converse path.
- Rotation or `updatedAt` version mismatch invalidates existing converse sessions on the next request.

**Relationships**:
- Belongs to one workspace and one agent.
- Issues many converse sessions over time.

## Agent Role Permission Set

**Source**: `AccountAccessService`.

**Fields / constants**:
- `PUBLIC_CHAT_PERMISSIONS`: existing public chat permissions.
- `public_chat.retrieval.query`: new permission for agent-aware grounded answer.
- `public_chat.documents.read.scoped`: new permission for sanitized agent-scoped document resources.
- `AGENT_CONVERSE_PERMISSIONS`: `PUBLIC_CHAT_PERMISSIONS` plus the two new read permissions.

**Validation rules**:
- `agent` role allows only membership in `AGENT_CONVERSE_PERMISSIONS`.
- `agent` role does not allow workspace settings, document management, or other-agent access.

## Converse Session

**Storage**: Signed session token using the existing `publicChatSession` issuer shape, plus persisted conversation/history through existing tables.

**Fields**:
- `publicSessionId`: server-owned conversation handle.
- `workspaceId`.
- `agentId`: copied from the grant at issuance; no tool parameter or URL path may select another agent.
- `grantId`.
- `grantVersion`: rotation/`updatedAt` value from the issuing grant.
- `sourceChannel`: `mcp`.
- `sourceOrigin`: null; Origin is not an authority axis.
- `expiresAt` / TTL.
- `resumeToken`: existing 30-day resume flow where applicable.
- `oauthClientId`: optional, US4.
- `endUserIdentity`: deferred until US3 and spec 097 merge.

**Validation rules**:
- Signature and TTL must pass.
- Every MCP request re-loads the grant by `grantId`, evaluates revoked/disabled/expired constraints, verifies `channel = mcp-converse`, and verifies `grantVersion` match.
- A revoked, disabled, rotated, expired, or deleted-agent grant fails the next request.
- Long turns must not fail solely because session TTL crosses during the in-flight turn; validation happens at request start.

**State transitions**:
- `launch token exchanged` -> `active signed session`.
- `active` -> `invalid` on TTL expiry, grant expiry/revoke/disable/rotation, agent unavailable, or version mismatch.
- `expired with valid resume` -> `new active session` after re-exchange and grant revalidation.

## Ask Agent Turn

**Storage**: Existing conversation/history records.

**Fields**:
- `message`: user input.
- `publicSessionId`: session conversation handle.
- `agentId`: from session.
- `sourceChannel`: `mcp`.
- `response`: assistant answer from existing turn loop.
- `citations`: included/omitted according to the agent's configured behavior.

**Validation rules**:
- No `agentId` input parameter accepted.
- Runs the existing agent turn loop with persona, directives, routines, retrieval, and history.
- User-facing assistant copy is generated by the LLM through the turn loop.

## Grounded Answer Request

**Storage**: No new storage. Uses existing retrieval and document/chunk stores.

**Fields**:
- `query`.
- `session`: converse session principal.
- `agentId`: from session.
- `options`: bounded request options only if supported by existing retrieval contracts.

**Validation rules**:
- Requires `public_chat.retrieval.query`.
- Uses bound agent retrieval settings: rewrite, rerank, source scope, citation policy.
- Does not use system defaults when an agent has configured retrieval.

## Agent Document Resource

**Storage**: Existing document records and source content.

**Fields**:
- `uri`: MCP resource identifier that is opaque to clients and scoped to the session/agent.
- `title` / display metadata safe for public surface.
- `mimeType` / content type.
- `content`: sanitized readable content if policy allows.
- `citationMetadata`: only fields allowed by the agent citation/public policy.

**Validation rules**:
- Requires `public_chat.documents.read.scoped`.
- Lists/reads exactly documents visible to the bound agent.
- No create/update/delete/reprocess actions.
- Does not leak internal document ids, chunk ids, private storage paths, or hidden metadata beyond the configured citation policy.

## OAuth Converse Client (US4)

**Storage**: Existing or new OAuth client/session storage as selected during implementation; no Scope 2 authority.

**Fields**:
- `clientId`, registration metadata, redirect URIs.
- PKCE challenge/verifier metadata for authorization code exchange.
- authorization code, access/session token, refresh credential.
- bound grant/session/agent.

**Validation rules**:
- Protected-resource metadata advertises the authorization server.
- PKCE required.
- Authorization and refresh issue sessions equivalent in authority to launch-token exchange.
- Refresh fails when the underlying grant is revoked, disabled, expired, rotated, or agent unavailable.

## Deferred End-User Identity (US3)

**Status**: Blocked until spec 097 / PR #783 merges.

**Fields**:
- signed end-user id and visitor context from spec 097.
- session binding `(grant, agent, end-user identity)`.

**Validation rules**:
- Tampered/unsigned identity rejected.
- Histories isolated per end user under one credential.
- Not designed or implemented in active Scope 1 tasks beyond preserving optional session slots.
