# Custom Instruction

## Summary
Add workspace-specific answer guidance that applies after evidence is assembled.

## Details
### Overview

This is the workspace-level instruction for how answers should be written after evidence has been assembled.

### Appropriate Uses

- formatting rules
- answer style
- citation style
- domain-specific response habits

### Inappropriate Uses

Do not use this as a bandage for retrieval problems.

If the wrong evidence is being found, the fix belongs in ingestion or retrieval settings, not here.
