# Operator

## Summary
Choose how the metadata field should be compared against the rule value.

## Details
### Overview

This is the comparison method applied to the selected metadata field.

It answers questions like:

- must the value be exactly equal?
- is containing the text enough?
- should the value be above or below a threshold?

Choose the operator based on how clean and standardized the metadata really is.
