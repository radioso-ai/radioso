# Source Scope

## Summary
Choose which workspace sources this agent may retrieve from.

## Details
Source scope limits the evidence pool before retrieval starts.

With **All sources**, the agent can search every persisted source in the workspace. This is the broadest option and is usually right for a general assistant.

With **Selected sources**, the agent can only retrieve from the sources you choose. Use this when an agent should stay focused on a product area, customer-facing collection, internal policy set, or another bounded knowledge source.

The setting does not change document permissions outside this agent. It only controls which sources are eligible for this agent's grounded answers.
