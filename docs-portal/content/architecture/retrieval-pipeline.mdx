# Retrieval pipeline

At a high level, Radioso moves through query interpretation, candidate retrieval, selection, prompt assembly, and answer presentation. The retrieval settings surface exists to make those stages tunable.

## Why this matters

If answer quality is off, retrieval tuning is usually the first place to look before prompt tweaking.
