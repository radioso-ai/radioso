# Data Model: Precise Citation Placement

## Retrieved Result Number

- **Purpose**: Stable ordinal assigned to each retrieved context before answer generation.
- **Fields**:
  - `resultNumber`: positive integer unique within one answer generation attempt
  - `documentId`: account-scoped document identifier
  - `chunkId`: retrieved chunk identifier
  - `title`: human-readable source label
  - `content`: source text used for grounding and validation
- **Relationships**:
  - One retrieved result number maps to exactly one retrieved context.
  - One completed answer may reference zero or more retrieved result numbers.

## Raw Citation Anchor

- **Purpose**: Explicit source reference emitted in the raw model answer.
- **Fields**:
  - `rawText`: literal anchor text found in the generated answer
  - `resultNumbers`: ordered list of referenced result numbers
  - `valid`: whether every referenced number maps to a retrieved result for the current answer
- **Lifecycle**:
  - Generated by the model in raw answer text
  - Parsed and validated during answer normalization
  - Removed from the user-visible answer text after normalization

## Presented Answer Segment

- **Purpose**: Visible answer span with exact citation placement metadata.
- **Fields**:
  - `text`: visible text fragment to render
  - `citationIndices`: optional ordered list of citation indices that apply at the end of that segment
- **Rules**:
  - Segments preserve original answer ordering.
  - Citation indices reference only validated visible citations.
  - Repeated citations at the same boundary are deduplicated.

## Visible Citation Reference

- **Purpose**: Source entry rendered in the frontend and used for document opening.
- **Fields**:
  - `documentId`
  - `chunkId`
  - `title`
- **Rules**:
  - Visible citations are created only from valid anchors.
  - Unused retrieved contexts do not appear in the visible citation list.
