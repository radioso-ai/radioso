# Metadata Key

## Summary
Choose the metadata field this rule should inspect.

## Details
### Overview

This is the metadata field the rule evaluates.

Examples:

- `language`
- `sourceUrl`
- `publishedAt`

If the key is wrong or inconsistently populated, the rule becomes unreliable.
