# Build agents your customers talk to

Radioso is a self-hosted platform for conversational agents. An agent answers from your own data with citations, acts through your tools by following the procedures you author, and hands off to a person when it should — inside the rules you set. You can reach the same agent from the app, API, SDK, MCP, public chat, or the website widget.

<Callout type="info" emoji="↗">
  Choose one path first: evaluate locally, integrate through the API, or launch the website embed.
</Callout>

## What success looks like

<Steps>
### Reach a visible result

Do not stop at setup. Upload one real document, ask one real question, or load one real agent surface.

### Check the evidence

The answer should be grounded, the citations should be traceable, and the app, API, MCP, or widget flow should behave the way the docs say it behaves.

### Understand the system

Use the architecture and operator guides to understand how agents, retrieval, document processing, and deployment fit together.
</Steps>
