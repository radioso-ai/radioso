# Radioso for intelligent knowledge agents

Radioso is built for teams that need self-hosted knowledge agents they can trust. Agents answer from workspace knowledge, keep citations traceable, expose diagnostics, and can be used from the app, API, SDK, MCP, public chat, or an Enterprise website widget.

<Callout type="info" emoji="↗">
  Choose one path first: evaluate locally, integrate through the API, or launch the website embed.
</Callout>

## Choose your path

<Cards num={3}>
  <Cards.Card title="Evaluate locally" href="/quickstarts/run-locally">
    Bring up the full stack with Docker, create or join a workspace, upload a document, and verify one agent answer in your own environment.
  </Cards.Card>
  <Cards.Card title="Launch the website embed" href="/quickstarts/website-embed">
    Configure the Enterprise widget, allow exact origins, verify session bootstrap, and test both approved and blocked origins before rollout.
  </Cards.Card>
  <Cards.Card title="Integrate API-first" href="/quickstarts/api-first-success">
    Create an account, reveal a workspace token, upload content, and ask a question with plain HTTP or the TypeScript SDK.
  </Cards.Card>
</Cards>

## What success looks like

<Steps>
### Reach a visible result

Do not stop at setup. Upload one real document, ask one real question, or load one real agent surface.

### Check the evidence

The answer should be grounded, the citations should be traceable, and the app, API, MCP, or widget flow should behave the way the docs say it behaves.

### Understand the system

Use the architecture and operator guides to understand how agents, retrieval, document processing, and deployment fit together.
</Steps>
