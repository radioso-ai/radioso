# Suggested Questions

## Summary
Turn assistant follow-up question chips on or off.

## Details
Suggested questions are assistant behavior. They are optional grounded continuations generated from the retrieved material when the assistant used retrieval for the current answer.

Suggestions can push deeper on the same subject or widen to adjacent grounded areas that still fit the active conversation goal.

Retrieved material can influence the direction of a suggestion, but the chip should still make sense from the visible conversation. A suggestion should not introduce a hidden person, title, event, date, or other specific detail unless the assistant answer or the user already mentioned it.

When the assistant answer offers a useful next step, suggested questions can also act as short ways to accept that next step.

If the assistant cannot support a broader branch honestly from the available material, it should use another supported direction instead of inventing filler.

Turn this off when you want answers to end cleanly without any suggested next steps.

Turn it on when you want the assistant to keep surfacing short, clickable follow-up questions that stay tied to the workspace evidence.
