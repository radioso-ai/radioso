# Warmth

## Summary
Control how terse or warm the assistant sounds when presenting answers.

## Details
### Overview

This setting controls the tone of the final answer after retrieval and evidence selection are complete.

### Lower Values

- terse
- direct
- efficient

### Higher Values

- softer
- more conversational
- more guided

### Limitation

This setting changes style, not evidence quality.

If the answer is poorly grounded, changing warmth only changes how nicely the same weak answer is delivered.
