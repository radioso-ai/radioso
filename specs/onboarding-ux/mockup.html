API & SDK

Issue a credential for the REST API, TypeScript SDK, or MCP. Personal tokens act as you; service accounts belong to the workspace.

  • Read & converse — a service account that can chat and search, but can’t change settings. Start here.
  • Manage workspace — full admin. Only for tools that configure Radioso itself.
Expires in 90 days by default — rotate or revoke anytime under Settings → API access.
Shown once — store it now. You can rotate it later, but not re-read it.
Credentials follow the role-bound model (PR #1142) with a least-privilege default and plain-language options — no newcomer should have to decode “role ceiling” to make a safe choice, and “admin to be safe” is exactly the wrong habit to teach. The shown-once secret blocks Finish until the user confirms they stored it, because the very next button would otherwise swallow it forever.
