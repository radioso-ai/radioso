# Retrieval tuning

Retrieval tuning works best when you change settings in pipeline order. That keeps you from using prompt instructions to mask a search problem.

## Recommended tuning order

<Steps>
### Confirm ingestion quality first

Make sure the document was processed successfully and chunked with a strategy that matches the structure of the source material.

### Tune query interpretation

If users ask vague, shorthand, or multi-part questions, start with `queryRewriteEnabled` and the semantic or lexical rewrite instructions.

### Tune candidate depth

Adjust `vectorTopK` and `similarityThreshold` to control how many semantic matches survive early filtering.

### Tune final ranking

Enable reranking and then adjust `rerankTopK` if the right chunks are being retrieved but not promoted into the prompt context.

### Add metadata constraints

Use metadata rules or request-level metadata filters when the right answer exists but should come from a narrower subset of documents.

### Adjust response behavior last

Use `customInstruction`, citation display, conversation mode, and support validation after the retrieval evidence looks healthy.
</Steps>

## Highest-leverage settings

- `vectorTopK`: raises or lowers the semantic candidate pool
- `similarityThreshold`: removes weak semantic matches early
- `rerankEnabled`: decides whether final ranking gets a second pass
- `rerankTopK`: controls the size of the rerank candidate set
- `metadataRules`: boosts or constrains candidates based on document metadata
- `queryRewriteEnabled`: helps when user phrasing does not match stored document language

## Symptom to setting map

- Right documents never appear: raise retrieval depth or revisit chunking.
- Too many near-matches appear: raise threshold or add metadata constraints.
- Right documents appear but wrong snippets win: enable or retune reranking.
- Answers sound plausible but unsupported: inspect citations and validation outcomes before changing style instructions.

<Callout type="warning" emoji="!">
  `customInstruction` can improve answer style, but it will not fix missing or weak evidence.
</Callout>
