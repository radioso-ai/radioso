# Use cases

## Embedded support assistant

Use Radioso when you want a customer-facing assistant on a website that answers from controlled content instead of improvising from model priors.

## Team knowledge assistant

Use workspace-scoped documents and settings when different teams or customers need isolated behavior and content.

## API-driven document Q&A

Use the API or SDK when you want Radioso to sit behind your own UI or workflow.
