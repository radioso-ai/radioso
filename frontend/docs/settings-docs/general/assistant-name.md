# Assistant Name

## Summary
Optional name the agent uses when it introduces itself at the start of a conversation.

## Details
Set a name here when you want the opening message to introduce the agent consistently — "Hi, I'm Ada from Support" rather than a generic hello. It shapes only the self-introduction; the rest of the agent's persona and tone come from its other settings, and the name does not make the agent repeat itself on every reply.

Leave it blank when a nameless greeting reads better, or when the agent's persona already carries its identity.
