# Suggested Question Count

## Summary
Choose how many assistant follow-up question chips may appear per answer.

## Details
This assistant setting is a hard cap, not a target. If the retrieved material only supports one or two honest continuations, the assistant should return fewer than the configured maximum.

Use lower values for a tighter, calmer chat flow. Use higher values when discovery matters and you want the UI to present more branching paths after each answer.
