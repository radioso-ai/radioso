# Proactive Greeting Enabled

## Summary
When enabled, fresh conversations start with an assistant-first greeting.

## Details
Turn this on when a new chat should open with a short introduction before the user sends a message. The greeting uses the workspace identity settings and any request-scoped locale hint provided by the client.
